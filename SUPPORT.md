# Support

Every `zachthedev` repository takes questions the same way.

- A defect, with the steps that show it: an issue on the repository it concerns. The issue form asks for what a
  fix needs.
- A question about using a project: its Discussions tab where the repository has one, and otherwise its issue
  tracker under the feature form.
- A security problem: never an issue. [SECURITY.md](SECURITY.md) says how to report one privately.
- Anything else: [hey@zachthe.dev](mailto:hey@zachthe.dev).

One person maintains these repositories, so a first reply can take up to a week.
